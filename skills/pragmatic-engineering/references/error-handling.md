# error handling
Throw exceptions by default; Result when justified. Custom errors for all business errors. Mandatory base error class per existing architectural layer (DomainError, ApplicationError, InfrastructureError, PresentationError as applicable). Inner layers independent of frameworks. Group related errors by business responsibility. Stable codes mandatory for public business errors. Prefer guard clauses and early returns. Catch only for recovery, translation, cleanup or context; preserve cause. Log once at responsible boundary; redact secrets. Retry only transient safe operations. Roll back atomic failures. Domain never throws HTTP exceptions.
