# Pragmatic Engineering v3.0
1. Inspect existing conventions, contracts and reusable implementations.
2. Identify requirements, invariants and smallest complete solution.
3. Read relevant references. Justify abstractions; obtain approval for major changes and new dependencies.
4. Implement cohesive code; small related reversible improvements allowed. Preserve correctness.
5. Review diff, fix violations or request exception. Run affected tests.
6. Report changes, decisions and tests briefly.
